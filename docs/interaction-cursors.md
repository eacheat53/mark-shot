# 鼠标光标与交互状态

光标根据指针下方的操作区域和当前交互状态变化。控件禁用时使用箭头；背景任务只影响所属窗口，不覆盖其他窗口的光标。

| 操作区域 | 悬停状态 | 按住或执行时 | 结束后 |
| --- | --- | --- | --- |
| 按钮、开关、下拉入口 | 手型 | 保持手型 | 禁用时恢复箭头 |
| 标签页、设置分类 | 可用项目显示手型，空白和禁用项目显示箭头 | 保持当前项目语义 | 按当前位置重新判断 |
| 单行输入、文本编辑器、钉图内可选文字 | I 形 | 选择或编辑文字时保持 I 形 | 按当前位置重新判断 |
| 参数滑块 | 张开手型 | 左键按住时为闭合手型 | 释放、隐藏或禁用时清理抓取状态 |
| 截图选区、绘制工具、尺子定位 | 十字 | 保持精确定位光标 | 切换工具后更新 |
| 截图选区边缘、标注控制点 | 对应方向的缩放光标，控制点使用四向光标 | 保持操作方向 | 重新命中当前边缘或内容 |
| 可移动选区、标注、钉图、标题栏、工具栏握柄 | 张开手型 | 闭合手型 | 松开后恢复悬停语义 |
| OCR 原图页面 | 箭头 | 无拖动操作 | 保持箭头 |
| 滚动截图区域握柄、可拖动概览 | 张开手型 | 闭合手型 | 释放或失去抓取后恢复 |
| OCR、扫码、上传、钉图翻译 | 当前任务窗口显示忙碌光标 | 可交互控件保留自身光标 | 成功、失败、取消或超时后恢复 |

截图和标注优先保留正在执行的抓取或缩放方向。指针进入工具栏、输入框等控件后，使用该控件的光标。软件指针和画笔预览接管显示期间才隐藏系统指针。

钉图的缩放与文字选择优先于后台翻译状态。原生窗口移动可能由窗口管理器接管鼠标释放事件，因此重新进入窗口或收到没有左键的移动事件时，也会清理移动状态。

普通窗口交给窗口管理器移动或缩放时，实际光标遵循桌面的规则。应用在重新获得指针后恢复悬停光标；浮层窗口由应用维护抓取和缩放光标。

标准控件的规则集中在 `src/ui/interaction_cursor.cpp`；截图、钉图、OCR 标题栏和滚动截图分别维护自身操作状态。截图任务通过作用域恢复忙碌状态，包含提前返回和嵌套调用。

控件状态回归检查：

```sh
QT_QPA_PLATFORM=offscreen ctest --test-dir build -R '^interaction-cursor$' --output-on-failure
```

实际桌面检查应覆盖：选区建立与调整、标注移动与控制点缩放、文字编辑、工具栏移动、钉图移动与边缘缩放、OCR 页面切换与标题栏移动、录制选项、滚动截图概览，以及设置字段的启用和禁用状态。
